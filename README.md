# Property Deal Tracker App

A simple and powerful web application to help property investors and real estate professionals track, calculate, and manage deals—whether it's flipping houses, managing rentals, or seller financing.

## 🚀 Features

- Track and analyze property deals
- Automatic calculation of:
  - Total investment
  - After Renovation Value (ARV)
  - Target resale value
  - Expected profit
  - Estimated monthly cash flow
- Clean and intuitive interface
- Add new deals easily with dropdowns and inputs

## 🛠 Built With

- React (Next.js App Router)
- TailwindCSS
- Simple UI component system (Input, Button, Select, Card)
