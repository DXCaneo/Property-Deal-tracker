# Property Deal Tracker App

A simple and powerful web application to help property investors and real estate professionals track, calculate, and manage deals—whether it's flipping houses, managing rentals, or seller financing.

## 🚀 Features

- Track and analyze property deals
- Automatic calculation of:
  - Total investment
  - After Renovation Value (ARV)
  - Target resale value
  - Expected profit
  - Estimated monthly cash flow
- Clean and intuitive interface
- Add new deals easily with dropdowns and inputs

## 🛠 Built With

- React (Next.js App Router)
- TailwindCSS
- Simple UI component system (Input, Button, Select, Card)

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or newer)
- npm or yarn

### Installation

```bash
git clone https://github.com/yourusername/property-deal-tracker.git
cd property-deal-tracker
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app in your browser.

## 🌐 Deployment

This app is optimized for [Vercel](https://vercel.com):

1. Upload the code to a GitHub repo
2. Go to [vercel.com](https://vercel.com) and import the repo
3. Deploy instantly

## 📁 Project Structure

